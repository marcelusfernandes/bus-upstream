# Decision Record

Escolha formato proporcional: product/design decision, ADR, decision note ou
checkpoint issue.

Registre Date, Origin, Question, Context, Options, Recommendation, Decision,
Why, Accepted trade-offs, Evidence IDs, Reversibility, Affected artifacts,
Status e Owner approval ref quando necessário.

Silêncio nunca é aprovação.
