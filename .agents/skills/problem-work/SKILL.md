# Problem Work

Leia `references/matrix-and-gates.md`.

## mode=explore — Vague + Unknown

Descubra fenômeno e problem candidates.
Pergunte: o que acontece, com quem, em qual contexto, frequência/severidade,
o que é sintoma/causa possível/consequência, quais evidências existem e o que
continua unknown.

## mode=frame — Vague + Known

Torne Definition = Concrete. Produza:
- problem statement sem solução;
- current state;
- desired state/outcome;
- population/context;
- observable gap;
- impact;
- scope/out-of-scope;
- competing hypotheses;
- Evidence IDs.

## mode=investigate — Concrete + Unknown

Resolva incógnitas capazes de mudar o framing: causas concorrentes, segmentos,
exceções, confounders e evidência que poderia refutar a formulação atual.
