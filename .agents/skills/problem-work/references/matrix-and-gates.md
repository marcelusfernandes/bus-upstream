# Matrix and gates

## Axes

- X — Knowledge: Unknown → Known
- Y — Definition: Vague → Concrete

## Problem

| Definition | Knowledge | State |
|---|---|---|
| Vague | Unknown | Explore |
| Vague | Known | Frame |
| Concrete | Unknown | Investigate |
| Concrete | Known | Ready |

## Solution

| Definition | Knowledge | State |
|---|---|---|
| Vague | Unknown | Explore |
| Vague | Known | Shape |
| Concrete | Unknown | Validate |
| Concrete | Known | Deliver |

## Problem Definition → Concrete

Todos:
- current state observável;
- população/segmento/contexto;
- observable gap;
- desired outcome;
- scope/out-of-scope;
- claims centrais rastreáveis.

## Problem Knowledge → Known

Todos:
- existe base de evidência suficiente para a decisão;
- população e janela são compatíveis;
- contradições relevantes estão resolvidas ou nomeadas;
- incógnitas capazes de mudar o problem statement foram resolvidas ou aceitas explicitamente.

## Solution Definition → Concrete

Todos:
- intervention mechanism;
- user flow/states;
- business/product rules;
- edge cases/fallbacks relevantes;
- constraints/non-goals;
- metrics/observability.

## Solution Knowledge → Known

Assumptions críticas de:
- value;
- usability/comprehension;
- technical feasibility;
- operation/performance/cost;
- risco relevante ao domínio;
foram verificadas ou explicitamente aceitas como risco.

`Known` não significa “resultado garantido”; significa que não existe uma incógnita
crítica escondida impedindo a decisão de avançar.
