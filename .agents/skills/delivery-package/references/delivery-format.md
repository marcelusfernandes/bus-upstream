# Delivery format

Adapte ao template do projeto, preservando pelo menos:
- Tamanho
- Parent / Sub-issues
- User Story
- Contexto
- Cenário atual
- Problema
- Consequências
- Solução
- Resultado esperado
- Acceptance Criteria
- Proof / Validation
- Files / Scope
- Fora de escopo
- Referências
- Decision refs
- Evidence refs

M/L deve ser decomposto antes da implementação.
