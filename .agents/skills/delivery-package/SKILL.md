# Delivery Package

Leia `references/delivery-format.md`.

Pré-condições: Problem Ready, Solution Deliver, readiness approved e human gates
bloqueantes resolvidos.

1. Gere milestone de delivery quando a iniciativa justificar fase.
2. Se M/L, gere epic e decomponha em subissues.
3. Cada issue tem AC verificável.
4. `Proof`/Validation diz como provar.
5. `Files`/Scope delimita alteração quando aplicável.
6. Decisões/evidências viram referências.
7. Não reabra decisão upstream silenciosamente.

Se precisar inventar comportamento, AC, Proof ou Files, rejeite o handoff.
