# Product Upstream

AI-agent-run product upstream: from a stakeholder demand to a clear **Business problem**,
**User problem** and **Solution** direction, packaged as a PRD for the Product Designer.
Agents do the work; a junior PM makes every high-impact decision.

Status: **redesign in progress** — the specification lives in [`spec/v1/`](spec/v1/README.md).
Agents, skills, scripts and GitHub templates will be rebuilt from it.
